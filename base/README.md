# Base fixa do app

Arquivos que acompanham o Pre-Crime Studio e são copiados para a pasta de trabalho na primeira configuração:

- `streets/` — `grids_area_XX.geojson` (malha de células de cada área) e `ruas_area_XX.geojson` (malha viária)
- `pois/` — `pois_area_XX.geojson` (pontos de interesse: bares, delegacias etc.)

Ficam fora do git (cerca de 180 MB). No empacotamento, `base/` vai em `extraResources`.
